# Revision log

| Version | Change | Why |
| --- | --- | --- |
| v0.1 | Simulated AI-safety summit with model-played delegations | Initial idea |
| v0.2 | Five rounds per report, two-thirds vote, public gallery with ratings; rapporteur does not judge; red-line tables; at most three cycles | Team discussion; stop the model agreeing with everything; reproducibility |
| v0.3 | Convening phase, attendance conditions, parallel forums, Track 2 expert channel, outcome types, debrief and replay | Instructor feedback: the hardest problem is that parties will not sit down together |
| v0.3-impl | Static browser app with no backend; leaderboard is local to one machine; claims move from one `claims.csv` into each delegation's YAML file and are exported as CSV on demand; new Research page lists, per delegation, the materials still needed and the sourcing status of every rule | Easy to clone and run; one file per delegation avoids merge conflicts between team members |
| v0.4-ui | Negotiation became a fixed three-column workspace that shows how each delegation leans on the current draft; votes are revealed seat by seat on the round table; the outcome reads as a communiqué with the adopted text; the debrief answers five questions instead of listing raw data | Lead's walkthrough: the composer was below the fold, the table carried no information, the vote had no weight, the debrief was a 3,800px data dump |
| v0.4-balance | Two trade-offs now sit in the text: who verifies results (China: national execution; US, EU, evaluator: checkable by someone else) and the jailbreak threshold (China 5–10%, evaluator 3% or less). Major powers need a score of 3 | Walkthrough: tabling every clause and saying one sentence produced a 6–0 full agreement in the second cycle |
| v0.4-effect | Every statement now says what it did: the argument recognised, who it moved, and the change in leaning ("Against → Wavering"); a statement that moved nobody says so. Offline trigger phrases widened, in English and Chinese | Owner feedback: "my statements should have a real effect" |
| v0.4-editor | Team → Delegations: add a delegation or edit any delegation's data in a form (conditions built from menus and shown as sentences), with a per-delegation checklist of what is still missing. Edits are kept in the browser and exported as the YAML file to commit. A delegation now needs only its own file | Owner feedback: teammates must be able to add participants and change their data without knowing YAML, and know what they are expected to do |
| v0.4-checks | An argument that eases a demand without yet changing a vote now reads "landed with …, but nobody has changed sides yet" instead of "moved nobody"; a change to the text that moves nobody says so instead of repeating the previous change. A third browser script checks that statements move the room and that a delegation can be edited, added, removed and recovered | Publication walkthrough: the chip under a statement said "moved" while the summary line said "moved nobody" |
