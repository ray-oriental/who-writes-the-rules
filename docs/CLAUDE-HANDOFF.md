## 已落地

- 正常入口加载真实 YAML，配置有错时显示文件和字段。游戏控制器在 `src/game/`，负责组织引擎和模型层、锁住异步步骤、按步骤自动存档。四个原始契约保持兼容。Vite 开发时用 `/?fixtures#/dev` 进入假数据预览。
- 英文界面贯通角色卡、前测、召集与出席、谈判、书记员报告及异议、投票、结局、复盘、后测和重玩。可在圆桌上查看出席和退场，调整条款参数，处理修正建议和让步。附议程限制的 Track 2 能产出技术附件并带回正式会议。
- 修了几处交互边界。条款太少时保留谈判和补条款入口。失去法定人数时可进入专家渠道或结束。专家会议结束后，召集界面恢复可选的正式会议形式。投票仍由规则引擎判定。
- **Research** 有六份代表团档案和一份共享档案，共 58 条断言、49 项研究任务。档案显示负责人、状态、检索线索、用途和引用，能按状态筛选并下载 `claims.csv`。团队用各自的 YAML 改 `owner` 和 `status`。配置实际仓库地址后，档案会显示对应文件的 GitHub 编辑链接。
- **Gallery** 在本机收录通过的提案和技术附件，支持评分和排名。**Admin** 能导出完成的会话和断言表，以及导入导出本机提案和评分。**Settings** 可选离线模板、直连和本机代理。
- [README](../README.md) 写了启动、离线包和团队配置流程。一个 [GitHub Actions 工作流](../.github/workflows/ci.yml) 串起 PR 校验、主分支 Pages 构建和 tag 发布，部署及发布以校验成功为前提。
